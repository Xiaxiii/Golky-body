# 酒馆内置网易云播放器

给 SillyTavern 1.19.0 加一个页面内的网易云音乐播放器：

- **后台保活**：音乐在酒馆页面里播放，iOS 就不会挂起这个页面。歌停了，多半说明页面被回收了。
- **锁屏看生成状态**：生成期间锁屏 / 控制中心的副标题显示「酒馆 · 正在生成…」，完成后显示「酒馆 · 回复已完成」，不用切回 Safari。
- **不拖慢启动**：启动时只多加载三个小文件（`manifest.json`、`index.js` 和收纳功能的 `dock.js`），不发任何接口请求；播放器界面和播放逻辑点开后才加载。

不改动柏宝箱、柏宝库和酒馆本身的任何文件。

## 安装

播放器分两部分，都要装：

| 部分 | 做什么 | 怎么装 |
|---|---|---|
| 前端扩展（仓库根目录） | 界面、播放、锁屏信息 | 酒馆里用 Git 链接一键安装 |
| 服务端插件（`server/netease-player/`） | 替页面去问网易云：搜歌、歌单、播放地址、扫码登录 | 在酒馆服务器上手动放文件 |

### 1. 前端扩展

酒馆顶部「扩展」（积木图标）→「安装扩展程序」→ 粘贴下面的链接 → 点「只给我安装」（管理员也可以点「给所有人安装」）：

```
https://github.com/Xiaxiii/Golky-body-
```

以后在「管理扩展」里可以一键更新、删除；也可以在顶部「扩展」→ 扩展设置的「网易云播放器」条目里点「检查更新」，有新版时点「更新」，再点「刷新页面」。这个按钮只更新前端；服务端插件版本落后时，条目里会提示到服务器上更新。仓库必须是公开的，别人才能用这个链接安装。

> 以前用 INSTALL.md 手动装过的，先删掉 `public/scripts/extensions/third-party/netease-player`，否则会装两份（播放器会提示重复，只启动其中一份）。

### 2. 服务端插件

按 [server/netease-player/README.md](server/netease-player/README.md) 操作：把 `server/netease-player` 文件夹放进酒馆的 `plugins/`、
`npm install`、在 `config.yaml` 里设 `enableServerPlugins: true`、重启酒馆。

### 升级到 0.6

0.6 修复了「收藏到歌单」「从歌单删除」总是提示失败的问题，修复在服务端插件里，前端和服务端都要更新：

1. 酒馆「管理扩展」里更新网易云播放器（前端），或在扩展设置的「网易云播放器」条目里点「检查更新」→「更新」→「刷新页面」。
2. 在服务器上用扩展目录里的新文件覆盖服务端插件，再重启酒馆（依赖没变，不用重新 `npm install`）：

   ```bash
   cp "$SRC"/*.mjs "$SRC"/package.json plugins/netease-player/ && pm2 restart start
   ```
   也可以按 INSTALL.md 整段重新粘贴，登录状态不受影响。

## 使用说明

1. iPhone 上刷新酒馆。三个入口均可打开播放器：顶栏下方的悬浮胶囊；输入框左边的魔法棒 →「网易云音乐」；顶部「扩展」→ 扩展设置里的「网易云播放器」条目。
2. **登录**：面板右上角头像 →「账号与设置」→「扫码登录」。手机自己的相机扫不到自己屏幕上的码，所以：
   截图 → 打开网易云 App →「扫一扫」→ 右上角从相册选这张截图 → 在 App 里确认 → 回到酒馆。
   也可以点「复制登录链接」作为备选。不登录也能搜歌，但只能放免费歌曲，也没有每日推荐、歌单和红心；VIP 歌需要登录 VIP 账号。
3. **首页**：打开面板先到首页，自上而下是：
   - 个人资料：头像居中，下面是昵称、简介、地区（省级；海外账号显示「海外」）和歌单数，背景取头像的颜色。点一下进入「账号与设置」。
   - 每日推荐：日期、前三首歌名，每天 6 点更新。
   - 我的歌单：账号里的全部歌单，右侧是刷新键。
   每日推荐和歌单都是一行一个：点这一行进入歌单页，点行尾播放键直接开始播放，不进歌单页。
   顶栏右侧是搜索、设置、收起；进入下一层后左上角出现返回键。收起后再打开，回到收起前的页面和位置。
4. **放歌**：歌单页点「播放全部」或「随机播放」，点歌名从这首开始放；搜索结果点歌名立刻播放。
   面板底部常驻正在播放条（封面、歌名、播放 / 暂停、下一首、播放队列），点它进入「正在播放」。
   「正在播放」底色取自封面，中间是封面，暂停时略微缩小；下面是歌名、红心、收藏到歌单、进度条，
   最下一排五个键：播放模式、上一首、播放 / 暂停、下一首、播放队列。顶栏显示正在放的歌单名，右侧是静音键和收起。
   大歌单会在快放完时自动接着加载后面的歌；歌单页滑到底也会自动加载下一页（每次只画看得到的那几十行，几千首的歌单也不卡）。
5. **换歌**：
   - 下一首：悬浮胶囊上的 ▶▶ 键，一次点击，不用展开。
   - 上一首 / 下一首：在底部正在播放条或「正在播放」的封面上左右滑动，左滑下一首、右滑上一首。
   - 指定一首：轻点胶囊展开播放卡片，卡片下半列出接下来的 3 首，点歌名即换，共两次点击。
     要选更靠后的歌，点「正在播放」或底部条上的列表键进播放队列，点歌名即换。
   - 换一个歌单：首页每一行行尾的播放键，一次点击开始播放。
6. **红心与收藏到歌单**：每首歌行尾的「⋯」打开操作单：下一首播放、加到队列末尾、红心、收藏到歌单；在自己创建的歌单里还有「从歌单删除」，
   在播放队列里是「移出播放队列」。这些操作直接写回网易云账号，网易云 App 里同步可见。红过心的歌在列表里歌名后有一颗小红心。
   收藏到同一歌单的重复歌曲会被拒绝并提示。
7. **歌单刷新**：在网易云 App 里加了歌、建了新歌单，点「我的歌单」或歌单页的刷新键，会跳过插件的缓存直接从网易云重新拉取。每次打开播放器面板也会在后台自动检查一次，
   正打开的歌单曲目数或更新时间变了就自动重新加载（10 秒内反复开关只查一次）。
8. **悬浮胶囊**：液态玻璃样式，默认在顶栏下方居中。
   - 显示封面、歌名和副标题（歌手或生成状态），右侧是播放 / 暂停键和下一首键。生成期间副标题为橙色「酒馆 · 正在生成…」，完成后为绿色「酒馆 · 回复已完成」。
   - 三级展开：轻点胶囊，原地弹性展开成灵动岛样式的黑色播放卡片：封面、歌名和「歌手 / 专辑」，右上是随播放跳动的声波（颜色取自封面），
     下面进度条和时间，一排按键是列表、上一首、播放 / 暂停、下一首、红心，最下面是接下来的 3 首。
     卡片上点列表键、封面或歌名，进入完整面板的「正在播放」；点卡片以外的地方收回胶囊。卡片在上半屏向下展开、下半屏向上展开，不出屏幕。
   - 完整面板打开期间胶囊隐藏，面板收起后恢复。按住胶囊可拖动，位置会记住。拖动上限为顶栏下沿，按当前美化主题的顶栏实际高度计算，换主题或转屏后自动重算。
   - 玻璃质感默认「通透」：模糊并提亮背后的聊天内容，加顶部高光、边缘反光和内侧厚度阴影，透明主题下照样看得清；按下胶囊有轻微回弹。
     手机上滑动聊天记录觉得卡时，在「账号与设置」或扩展设置的「玻璃质感」里改成「不透明」。
     酒馆生成回复期间，胶囊和面板自动改用实色底、停用背景模糊，生成结束后恢复。
   - 按主题文字颜色自动选浅色或深色玻璃，也可在「玻璃颜色」里指定。
   - 「常驻入口」可改为输入框上方的迷你播放条，或关闭。选「关闭」后任何常驻入口都不显示，从魔法棒菜单或扩展设置打开播放器。
   锁屏和控制中心可以播放、暂停、上一首、下一首、拖进度。
9. **静音播放**：不想听歌时，在「正在播放」顶栏右侧点静音键。不出声，照样保持页面不被挂起，锁屏 / 控制中心照样显示「静音播放」和生成状态，
   可以在锁屏上暂停 / 继续。再点一次静音键（或者点任意一首歌、上一首 / 下一首）就退出，回到刚才那首歌的位置接着放。
10. 页面被回收后重新打开：悬浮胶囊显示「轻点 ▶ 继续播放」（迷你播放条显示「继续播放」按钮），点一下就从上次的位置接着放（iOS 不允许网页自己出声，所以必须点一下）。
11. **收纳球**：屏幕边缘的贴边把手，用于收纳悬浮球。
   - 收纳：点把手 →「拾取」→ 点按屏幕上的悬浮球（如焦香鸡翅的悬浮球、本播放器的胶囊）→ 命名后点「收纳」。也可在「管理」的「可收纳」列表中直接收纳。
   - 调用：点把手展开面板，点图标即可。播放胶囊调用后原地展开为播放卡片，卡片收回时一并隐去。
   - 「管理」中每项有三个按钮：
     - 「直达 / 唤出」：直达，点图标即触发原悬浮球；唤出，点图标后原悬浮球原位浮现，点它使用，点别处自动隐去，适用于直达无响应的悬浮球。
     - 「隐匿 / 常驻」：隐匿，平时不在屏幕上显示；常驻，平时照常显示，收纳中同样可调用。
     - 「×」：移除，悬浮球恢复原状。
   - 把手可拖至左右任一侧，松手自动贴边，上限为顶栏下沿。收纳仅在样式上隐去原元素，不移动、不删除，原扩展的功能与设置不受影响。
12. **魔棒菜单编排**：菜单保持原有单列样式。点菜单末尾「编排」，点按条目依次切换：置顶 → 折叠（收入「更多」）→ 还原，点「完成」退出。编排状态下点按不触发原功能。
   两项功能可在顶部「扩展」→ 扩展设置的「收纳」条目中分别关闭，关闭后页面恢复原样。
13. 不想用了：「账号与设置」→「停止并关闭」停止播放、清空队列，同时收起悬浮胶囊或迷你播放条，刷新页面后仍保持收起；再次从魔法棒菜单或扩展设置打开播放器时恢复。

### 和柏宝箱一起用

- **关掉柏宝箱的「生成中静音保活」**。音乐本身就在保活，不想听歌时用播放器自己的「静音播放」；两个声音同时抢，iOS 会让其中一个停下来。
- **「生成完成提示音」先保持原样实测一次**：生成完成时音乐如果被打断，播放器会在 1 秒内自动接着放（「账号与设置」里的「提示音打断音乐后自动接着放」，默认开）。
  如果实测还是会断、或者觉得那一下中断不舒服，就关掉柏宝箱的提示音——锁屏上的「回复已完成」就是无声的完成提示。
- 柏宝箱的「消息后台生成」照常用。播放器不包装 `fetch`，不改生成请求。

### 生成状态是怎么判断的

在 1.19.0 源码里核对过，酒馆提供这些事件：`generation_started`、`stream_token_received`、`message_received`、
`generation_ended`、`generation_stopped`。**没有单独的「生成失败」事件**，失败时也只会触发 `generation_ended`。所以：

| 情况 | 锁屏副标题 |
|---|---|
| 开始生成（不含扩展在后台跑的 quiet 生成） | 酒馆 · 正在生成… |
| 生成结束并收到了新消息 | 酒馆 · 回复已完成 |
| 点了停止 | 酒馆 · 已停止生成 |
| 生成结束但没收到新消息（多半是出错了） | 酒馆 · 生成已结束 |

另外监听了酒馆在生成期间给页面加的 `data-generating` 标记作为备用信号：万一柏宝箱的后台生成模式下事件不触发，也能显示状态。
显示「已完成」后，过 3 分钟（可在设置里改）或回到酒馆页面时，恢复显示歌手名。

柏宝箱的「消息后台生成」我看不到源码，没法事先确认事件会不会触发。「账号与设置」的「诊断」里有**事件日志**（只留最近 10 条），记录每次生成事件、暂停、切歌和离开/回到页面，测试时看这里就知道哪个信号来了。

## 分阶段在 iPhone 上实测

**第一阶段：装好、能放**
1. 用焦香鸡翅的「加载体检」对比装前装后：启动阶段只多了 `netease-player/manifest.json`、`netease-player/index.js` 和 `netease-player/dock.js` 三个文件请求，没有 `/api/plugins/netease-player/` 请求。
2. 扫码登录成功，能搜歌，能打开「我喜欢的音乐」并播放。
3. 柏宝箱「消息后台生成」、第三方 QR 等功能正常。

**第二阶段：后台连续播放**
4. 锁屏后连续播放至少 3 首，切歌不断。
5. 锁屏 / 控制中心显示歌名和封面，播放、暂停、下一首能用。
6. 切到别的 App 再回来，页面没有重新加载（事件日志里没有新的「页面加载」），生成的回复完整。
7. 让页面被回收后重开，悬浮胶囊显示「轻点 ▶ 继续播放」，点一下接着放。
8. 悬浮胶囊拖动顺手，拖动时不误触播放 / 展开；展开成播放卡片、收回的动画流畅；通透玻璃下滑动聊天记录不卡；键盘弹出时不挡输入框（挡了就拖开）。
   底部正在播放条、「正在播放」的封面上左右滑动能切歌，上下滑动照常滚动页面。
   胶囊展开、点外面收回，反复十次，胶囊始终可见、可点；拖动胶囊后立刻点它能展开。
   「常驻入口」改为迷你播放条，条上的歌名、播放键、下一首、展开键逐个点一遍都有反应。

**第三阶段：锁屏生成状态**
9. 播放中发送消息，马上锁屏，看锁屏副标题是否变成「正在生成…」→「回复已完成」。
10. 回到酒馆，打开「账号与设置」看事件日志：有没有「开始生成」「生成结束 done」，有没有「暂停 被系统或其他声音打断」「自动恢复播放」。

第 9 条要看 iOS 是否会在页面处于后台时刷新锁屏信息，这一点只能实测。如果锁屏不刷新，这个功能就做不到，播放本身不受影响。

## 已知风险

- 网易云没有给个人用的播放接口，这里用的是社区维护的非官方接口（`@neteasecloudmusicapienhanced/api` 4.41.1）。网易云改版时可能失效，需要更新依赖或修代码。
- 有一定概率触发账号风控（比如要求验证）。只做了扫码登录，没有密码登录。
- 红心、收藏到歌单、从歌单删除会直接改动网易云账号里的数据。删除没有撤销，误删需要在网易云 App 里重新收藏。
- 网易云有时会拦截云服务器 IP（返回 460）。插件会把手机自己的 IP 一起传过去，一般能避开；安装时的自检用的是服务器 IP，自检报 460 不代表手机上用不了。
- 歌曲地址有时效（约 20 分钟），播放器按需获取、不缓存；暂停很久再继续时如果地址过期，会自动重新获取。
- 无版权、需要 VIP 的歌取不到地址，会提示并跳过；连续 5 首都放不了就停下。未登录 VIP 时只有试听片段的歌默认也会跳过（设置里可改）。
- 页面是 HTTP，所以「复制登录链接」用的是旧的复制方式；复制不了时会显示链接让你长按手动复制。以后上了 HTTPS，网易云返回的 http 音频地址需要改成 https（服务端 `lib.mjs` 的 `getSongUrl`）。
- 网易云登录 cookie 只存在服务器 `plugins/netease-player/data/`（目录权限 700，文件 600），不会返回给浏览器，也不在这个仓库里（`.gitignore` 排除了所有 `data/` 和 `cookie-*.json`）。

## 流畅度

0.6 按「只让合成层动、不重排、不重建」检查过一遍，在 CPU 降速 4 倍的 Chromium 里对比（iPhone 上的实际表现需要实机确认）：

| 操作 | 0.5.3 | 0.6 |
|---|---|---|
| 首次打开首页，新建的节点 / 图片 | 868 / 66 | 371 / 21 |
| 歌单里红心一首 | 481 / 63 | 40 / 2 |
| 播放队列页里切下一首 | 657 / 90 | 3 / 0 |
| 胶囊展开：重排次数 / 光栅化耗时 | 38 次 / 176 ms | 7 次 / 7 ms |
| 再次打开面板：最长一帧 | 33～50 ms | 33 ms |

- 胶囊展开、收回只对 `clip-path` 做过渡，宽高不动；卡片是纯黑底，展开期间关掉背景模糊，收回到最终大小后才恢复。
- 首页各块数据各自到达时只替换那一块，内容没变不碰 DOM；红心、切歌只改受影响的行；收起再打开沿用原来的页面，不整页重建。
- 背景模糊半径：胶囊 16px、面板 20px（原为 22px、30px）。首页个人资料和「正在播放」的柔焦背景是放大的 48px、60px 小图，不用 `filter`。
- 主题颜色没变时不再插入探测节点重算整页样式。

### 0.6.1：生成期间

在仿酒馆页面（200 条消息，每 30ms 追加一个字并滚到底，持续 5 秒）里，CPU 降速 6 倍对比。未在真实酒馆和 iPhone 上测量。

| 场景 | 样式重算次数 | 样式重算耗时 | 超过 50ms 的任务 |
|---|---|---|---|
| 不装扩展 | 168 | 15 ms | 0 |
| 0.6.0，胶囊显示中 | 469 | 83 ms | 0 |
| 0.6.1，胶囊显示中 | 170 | 24 ms | 0 |

- 0.6.0 多出的 300 次样式重算来自「正在生成」前那个闪烁的小圆点，生成全程每帧触发一次。0.6.1 改为不闪烁。
- 生成期间胶囊、迷你播放条和面板停用背景模糊：聊天文字逐字刷新时，模糊层不再每帧重算。
- 歌名或生成状态变化导致胶囊变宽时，不再当场量尺寸（会强制整页重排），改由 `ResizeObserver` 在浏览器排版后通知，再调整位置。
- 主题颜色检查由每帧一次改为 400ms 一次，生成期间不检查。
- 自检：每次生成结束，事件日志（「账号与设置」→「诊断」）记一条「生成结束 · 用时，页面最长停顿，本扩展占用」。
  「页面最长停顿」是生成期间主线程被占用的最长一段，「本扩展占用」是其中本扩展代码的累计耗时。前者大而后者只有几毫秒，说明停顿来自酒馆本身或其他扩展。
